Este programa en Java gestiona las ventas mensuales de tres departamentos durante los doce meses del año utilizando una matriz bidimensional y un sacanner con menú interactivo para cada opción que quiera realizar el usuario.

Sus métodos son los sigueientes:

validarIndices: Comprueba que la opción de departamento y de mes existan, evitando que el programa falle por un error de rango.

insertarVenta: Guarda o actualiza el monto ingresado en la posición correspondiente de la matriz.

buscarVenta: Consulta y muestra en pantalla la cantidad de dinero registrada en la celda seleccionada.

eliminarVenta: Reinicia el valor guardado en la celda del departamento y mes elegidos.
